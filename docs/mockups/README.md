# Макет интерфейса Scene Director

## Оформление групп

Открыть [group-cards.html](group-cards.html) в браузере. Слева — приближение текущего списка, справа — предложение с мягкой карточкой на группу. Это самостоятельный макет, не точная копия темы SillyTavern. Раскрытие групп, ползунки и включение синхронизированы для сравнения; остальные элементы показаны только для компоновки. Ширина именно панели: 370/320/276 px; параметры `?width=276&open=1` открывают первую группу. Данные искусственные, сеть и сохранение не используются.

## Предыдущий макет навигации

Открыть `interface.html` обычным браузером. Сервер и установка зависимостей не нужны.

- Кнопки А/Б сравнивают редактор внутри панели и отдельное окно. Список сцены у них общий.
- Выбор экрана показывает компьютер, 397 и 320 px. Для прямого открытия можно добавить `?width=397&variant=b&editor=1` к адресу файла.
- Название директивы открывает её редактор; «···» у группы — редактор группы. Сохранение и отмена показывают предлагаемый порядок работы.
- Ползунки, включение, добавление, удаление директив и Undo/Redo работают на примерной сцене. Перезагрузка сбрасывает изменения.
- Пресеты, мастер и промпт показывают размещение отдельных экранов. Импорт/экспорт, запросы к модели, отсчёт ходов и полноценная библиотека в макет не включены. Промпт — схематический просмотр примерных данных.

Макет не подключается к SillyTavern, не читает чаты, не сохраняет данные и не использует внешние ресурсы.

Проверено в локальном Chrome: обе формы редактора сохраняют введённое описание и возвращают список; основной список на 320/397 px и компьютере показывает три полные карточки в области высотой 900 px, переполнения по горизонтали нет. Реальная мобильная клавиатура и пользовательские темы пока не проверены.

Для выбора: удобно ли видеть только основные действия в списке; какой редактор предпочтительнее; достаточно ли явных кнопок сохранения и отмены; нужен ли быстрый доступ к закреплению без открытия редактора.
